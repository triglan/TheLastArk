# 상태이상 구현 프롬프트

현재 Unity 전투 구조(`EffectEntry → EffectEngine → CharacterStatus → BattleCharacter/BattleManager`)를 유지하며 상태이상을 구현한다.

- 새 프레임워크나 효과별 클래스를 만들지 않는다. `ActiveStatusEffect` 공통 데이터와 전투의 기존 이벤트 지점만 확장한다.
- 기존 `EffectType` 값은 에셋 직렬화를 위해 순서를 바꾸지 않고 새 값만 뒤에 추가한다.
- 에디터는 효과 타입 선택 후 필요한 필드만 표시한다. 지속형 기본값은 3턴이며 이름은 `수치`, `확률`, `지속시간`, `횟수`, `스킬칸`처럼 실제 의미를 표시한다.
- 지속시간형 재적용은 남은 턴과 신규 턴 중 큰 값을 사용한다. 독은 수치를 합산한다. 횟수형은 남은 횟수와 신규 횟수 중 큰 값을 사용한다.
- 행동 제한: 봉쇄(지정 스킬칸 금지), 피로(같은 스킬 연속 금지), 혼란(확률로 대상 무작위), 기절(행동 불가), 냉기(AP 비용 증가).
- 지속 피해: 출혈(턴 종료 수치 피해, 행동 후 절반 피해), 독(턴 종료 수치 피해 후 10% 감소), 화상(최대 HP 비율 피해, 받는 회복 50% 감소).
- 정신 피해: 공포(턴 종료 정신 피해, 잃은 정신력 비율만큼 증가), 압박(행동 후 정신 피해), 절망(정신 회복량 감소).
- 능력치: 힘/약화는 기본 공격력 ±%, 보호/취약은 기본 방어력 ±%, 관통은 공격 시 대상 방어력 일부 무시. 기본 3턴.
- 대응: 반격은 피격 횟수를 소비해 공격력만큼 반격, 도발은 공격 횟수를 소비해 대신 피격, 방호는 지정 대상의 피격 횟수를 소비해 시전자가 대신 피격한다.
- 상태 종료·정화 시 임시 수치가 남지 않아야 하며, 상태 효과 때문에 재귀 피격이나 무한 반격이 발생하지 않아야 한다.
- 최소 하나의 실행 가능한 검증 또는 Unity 컴파일에 준하는 정적 참조 검사를 남긴다.
