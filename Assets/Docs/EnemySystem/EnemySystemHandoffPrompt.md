# The Last Ark 적 시스템 구현 인수인계 프롬프트

아래 요구사항을 기준으로 Unity 프로젝트의 적 캐릭터 데이터, 전투 실행 구조, 편집기와 테스트를 단계적으로 구현하라.

## 작업 역할과 원칙

너는 Unity 2022.3 LTS 기반의 시니어 클라이언트 프로그래머다.

반드시 다음 원칙을 지켜라.

1. 기존 구조를 최대한 유지한다.
2. 필요한 경우에만 새 클래스를 만든다.
3. SOLID 원칙을 지킨다.
4. 런타임 성능과 Unity 직렬화 호환성을 고려한다.
5. 변경 전에 관련 코드와 모든 호출부를 조사한다.
6. 기존 사용자 변경사항을 덮어쓰거나 되돌리지 않는다.
7. enum의 기존 정수값을 재배열해 에셋 직렬화를 깨뜨리지 않는다.
8. 각 구현 단계마다 관련 테스트를 작성하고 실행한다.
9. 수정 결과를 전달할 때 수정된 파일과 핵심 변경점을 명확히 설명한다.
10. Unity Inspector 및 커스텀 편집기 설정 방법을 설명한다.
11. 적마다 전용 AI 클래스를 만들지 않는다.
12. 범용 행동 트리, 노드 그래프, 자유 수식 언어 같은 과도한 시스템을 만들지 않는다.
13. 정의되지 않은 상태이상을 임의로 추가하지 않는다. 특수 기믹은 패턴 행동 또는 런타임 변수로 표현한다.
14. 한 번에 전체를 구현하지 말고 아래 구현 순서대로 작은 단계로 나누어 검증한다.

## 프로젝트와 세계관

- 장르: 아포칼립스 판타지 + 마도공학
- 마도공학 국가 아르키움 유니온이 일으킨 영혼 폭발로 세계가 붕괴했다.
- 사람들의 영혼, 기억과 능력이 파편화되었다.
- 플레이어 4명은 영혼 조각을 모으며 자신을 복구하고 열차를 타고 방주로 향한다.

## 플레이어와 턴 기준

평균 플레이어 능력치는 다음과 같다.

- 체력 30
- 정신력 30
- 공격력 3
- 주문력 5
- 방어력 3
- 마법저항력 3
- 한 턴에 행동력만큼 스킬 사용 가능
- 평균적으로 한 턴에 1~2회의 공격 스킬 사용

한 턴은 다음 순서로 진행한다.

1. 플레이어가 행동력만큼 스킬 사용
2. 살아 있는 모든 적이 현재 행동 패턴 실행
3. 턴 종료 효과 처리

등급별 목표는 다음과 같다.

| 등급 | 목표 턴 | 전투 내 적 수 |
| --- | ---: | ---: |
| 약한 적 | 4턴 | 1명 |
| 중간 적 | 5턴 | 1~2명 |
| 강한 적 | 6턴 | 2명 |
| 엘리트 | 8턴 | 1~3명 |
| 보스 | 14턴 | 1~4명 |

적 수에는 엘리트와 보스 본체가 포함된다. 목표 턴은 밸런스 기준이며 조합에 따라 달라질 수 있다.

1스테이지 기준 능력치는 다음과 같다.

| 등급 | 체력 | 정신력 | 방어 | 마저 |
| --- | ---: | ---: | ---: | ---: |
| 약한 적 | 15 | 7~8 | 0 | 0 |
| 중간 적 | 22 | 11 | 0 | 0 |
| 강한 적 | 30 | 15 | 2 | 0 |
| 엘리트 | 60 | 30 | 4 | 2 |
| 보스 | 120 | 60 | 8 | 4 |

이는 기준점일 뿐이며 역할이 명확하다면 같은 등급 내에서도 크게 변형할 수 있다.

## 확정된 피해 규칙

다음 규칙은 확정 사항이다.

```text
물리 최종 피해 = ceil(max(0, 물리 원피해 - 최종 방어력))
주문 최종 피해 = ceil(max(0, 주문 원피해 - 최종 마법저항력))
순수 정신 피해 = ceil(max(0, 정신 원피해))
```

- 최소 체력 피해는 0이다.
- 연타는 각 타격마다 방어력을 따로 적용한다.
- 순수 정신 피해는 체력 보호막, 방어력과 마법저항력을 무시하고 정신력에서 차감한다.
- 정신력이 0이 되면 현재는 0으로 고정한다.
- 정신력 0에 적용할 `정신 붕괴` 패널티는 추후 구현 예정이다.
- 지금은 정신력이 처음 0에 도달했음을 알릴 확장 지점만 준비한다. 정신 붕괴 규칙을 하드코딩하지 않는다.
- 스킬은 고정 정신 피해를 줄 수 있다.
- 체력 피해를 주는 데 성공했을 때 추가 정신 피해를 줄 수 있다.
- 실제 체력 피해에 비례한 정신 피해를 줄 수 있다.
- 별도 지시가 없으면 `피해 성공`은 보호막과 방어 처리 후 실제 체력이 1 이상 감소한 경우다.
- 비례 정신 피해는 실제로 감소한 체력을 기준으로 한다.

적에게 별도의 숨겨진 공격력 수치를 더하지 않는다. 적의 공격 기본값은 패턴에 적힌 피해다.

```text
적 물리 원피해 = 패턴 물리 피해 + 현재 힘 - 현재 약화
적 주문 원피해 = 패턴 주문 피해 + 현재 증폭 - 현재 쇠약
적 정신 원피해 = 패턴 정신 피해 + 해당 적의 정신 피해 증가량
```

`물리 3×3 + 공격 후 힘 +1`은 현재 3연타를 모두 계산한 뒤 힘이 증가하며, 다음 물리 공격부터 각 타격에 +1이 적용된다.

## 확정된 상태와 지속 규칙

상태이상은 다음 범위만 사용한다.

### 행동 방해

- 봉쇄: n턴간 해당 스킬칸 사용 불가
- 피로: n턴간 같은 스킬 연속 사용 불가
- 혼란: n턴간 스킬 사용 시 일정 확률로 대상 무작위
- 기절: n턴간 행동 불가
- 냉기: n턴간 스킬 행동력 소모 +n

### 지속 피해

- 출혈: 턴 종료 시 체력 n 피해
- 출혈 상태의 캐릭터가 스킬을 사용할 때마다 `ceil(n/2)` 체력 피해
- 출혈 행동 피해는 연타 수가 아니라 스킬 사용 횟수를 기준으로 한 번 발동
- 독: 턴 종료 시 현재 독 수치만큼 체력 피해 후 독 수치 10% 감소
- 화상: 턴 종료 시 최대 체력 n% 피해, 받는 회복량 50% 감소

### 정신력

- 공포: 턴 종료 시 정신력 n 감소
- 압박: 행동할 때마다 정신력 n 감소
- 절망: 정신력 회복량 n% 감소

### 능력 변화

- 힘: 공격력 +n
- 약화: 공격력 -n
- 증폭: 주문력 +n
- 쇠약: 주문력 -n
- 견고: 방어력 +n
- 파쇄: 방어력 -n
- 항마: 마저 +n
- 침식: 마저 -n
- 관통: 대상 방어력 n% 무시
- 집중: 도발 무시

능력 변화는 퍼센트가 아니라 고정 수치다. 기간제로도, 전투 중 영구로도 부여될 수 있으며 UI에서 수치와 남은 턴 또는 영구 여부를 보여줘야 한다.

### 대응과 보호

- 반격: 다음 n번 피격 시 지정된 반격 피해 또는 공격력만큼 반격
- 반사: 다음 n번 피격 시 공격자의 공격력 중 해당 공격에 사용된 공격 능력치의 m%만큼 반격
- 도발: 다음 n번 공격을 대신 받음
- 보호: 다음 n번 대상이 받을 피해를 시전자가 대신 받음
- 반격, 반사, 도발과 보호는 연타의 각 타격마다 1회 차감한다.

### 보호막

- 보호막은 지속시간이 없으며 파괴되거나 다음 턴에 제거된다.
- 구현 기준은 `부여한 진영의 다음 행동 페이즈 시작 시 제거`로 한다.
- 적 턴에 얻은 적 보호막은 다음 플레이어 행동 페이즈 동안 유효하고 다음 적 턴 시작 시 제거된다.
- 플레이어 턴에 얻은 플레이어 보호막은 다음 적 행동 페이즈 동안 유효하고 다음 플레이어 턴 시작 시 제거된다.

### 하수인

- 전투 중 소환된 적에게 `하수인` 효과 또는 런타임 마커를 표시한다.
- 같은 `CharacterData`가 인카운터에 처음부터 배치된 경우에는 하수인이 아니다.
- 현재 하수인 처치도 일반 적과 동일하게 처치 관련 효과를 발동한다.
- 추후 적에 따라 달라질 수 있지만 지금은 정책 시스템을 미리 만들지 않는다.

## 직렬화 호환성

- 기존 `EffectType` enum 값의 순서와 정수값을 변경하지 않는다.
- 필요한 enum 값은 뒤에 추가한다.
- 현재 `Protection`과 `Vulnerable`은 기획의 고정 수치 견고/파쇄와 의미가 다를 수 있으므로 기존 에셋을 조사한 뒤 마이그레이션한다.
- 현재 `Guard`가 대신 피해를 받는 기획의 `보호`에 해당한다면 런타임 이름을 무리하게 바꾸지 말고 편집기 표시 이름으로 정리한다.
- 기존 적 패턴 에셋을 새 구조로 자동 또는 명시적으로 변환할 수 있어야 한다.

## 패턴과 대상 설계 원칙

- 적은 정해진 순서대로 행동하고 마지막 패턴 이후 첫 패턴으로 돌아간다.
- 최대 약 5패턴을 기본으로 한다.
- 사이클 종료 시 자동 성장하지 않는다.
- 모든 성장은 실제 패턴 행동 안에서 발생해야 한다.
- 공격 후 강화는 현재 공격이 끝난 뒤 적용되어 다음 공격부터 영향을 준다.
- 적의 특징은 플레이어 능력치 탐색보다 자신의 행동 순서, 충전, 연타, 관통, 반격과 성장에서 나온다.
- 체력이 가장 낮거나 높은 플레이어를 자동 공격하는 패턴은 사용을 지양한다.
- 아군 적을 치유하는 지원 행동의 `HP 최저` 선택은 허용할 수 있다.
- 특수 대상 지정은 적의 핵심 기믹일 때만 사용한다.

대상 기억 규칙은 다음과 같다.

- 조준 또는 포식으로 예고한 대상이 실행 전에 사망하면 해당 행동은 실패한다.
- 갈고리 약탈자 같은 일반 연계 공격의 기억 대상이 사망하면 새 무작위 생존 플레이어를 선택한다.

## 금지되는 자동 사이클 성장

현재 존재하는 다음 기능은 제거 또는 마이그레이션한다.

- `CharacterData.damageBonusPerCycle`
- `CharacterData.bleedBonusPerCycle`
- `EnemyAI.BuildRuntimeEffects()`의 완료 사이클 기반 자동 성장
- 캐릭터 편집기의 사이클당 힘/출혈 입력 UI

기존 데이터에 값이 있다면 마지막 공격 후 힘 증가, 출혈 부여 수치 증가 등의 명시적인 패턴 행동으로 옮긴다.

## 권장 최소 구조

기존 구조를 확장하고 신규 런타임 클래스는 가급적 다음 두 개로 제한한다.

### `EnemyRuntimeState`

일반 C# 런타임 객체로 만들며 `EnemyAI`가 인스턴스별로 소유한다.

보관할 값:

- 현재 패턴 번호
- 선언된 런타임 변수와 현재 값
- 기억한 대상
- 예고 대상
- 피해 측정값
- 탈취한 골드
- 소환 여부
- 행동 가능 턴
- 낙마, 방패 내림, 포식 예고 같은 현재 자세

`CharacterData` ScriptableObject 자체를 전투 중 수정하지 않는다. 같은 적이 둘 등장해도 런타임 값이 공유되면 안 된다.

### `EnemyActionExecutor`

담당 범위:

- 패턴 행동 단계 실행
- 대상 결정과 검증
- 고정값 및 런타임 변수 계산
- 선행 결과 조건 처리
- 결과를 다음 행동 단계에 전달

`EnemyAI`는 패턴 순서, 준비, 실행 요청과 다음 패턴 이동만 담당한다.

### 데이터 클래스

새로운 직렬화 데이터 클래스는 가능하면 `CharacterData.cs` 또는 적 데이터 전용 파일 하나에 모은다.

```text
EnemyPatternData
 ├─ patternName
 ├─ intent settings
 └─ EnemyActionStepData[]
     ├─ action type
     ├─ target settings
     ├─ execution timing
     ├─ base value
     ├─ hit count
     ├─ penetration
     ├─ duration mode
     ├─ runtime variable reference
     └─ previous result condition
```

실행 시점은 최소한 다음을 구분한다.

- 공격 전
- 본 행동
- 각 타격 후
- 공격 전체 종료 후

## 행동 실행 컨텍스트

현재 정적 `_lastCalculatedValue`를 행동 한 번에만 존재하는 로컬 실행 컨텍스트로 교체한다.

컨텍스트가 보관할 값:

- 현재 대상
- 현재 타격 번호
- 직전 타격 입력 피해
- 직전 타격 보호막 피해
- 직전 타격 실제 체력 피해
- 누적 보호막 피해
- 누적 실제 체력 피해
- 실제 정신 피해
- 적중 여부
- 처치 여부

이를 이용해 다음을 구현한다.

- 체력 피해 성공 시 정신 피해
- 실제 체력 피해 비례 정신 피해
- 실제 희생 체력만큼 의식 축적
- 마지막 타격 적중 시 출혈
- 보호막 피해를 포함한 포식 저지

기존 API 호출 호환성이 필요하면 기존 `ReceiveDamage()`를 유지하고 상세 결과를 반환하는 새 내부 경로를 추가한다.

### 공격

- 연타
- 전체 공격

- 보호막 파괴

자유 입력 수식 언어나 임의 조건 그래프는 만들지 않는다.

## 의도 표시

적 의도는 적 행동 직전이 아니라 플레이어 턴 동안 보여야 한다.

권장 순서:

```text
플레이어 턴 시작
→ 모든 적의 다음 행동 준비
→ 대상과 의도 표시
→ 플레이어 행동
→ 적 턴 시작
→ 준비된 대상과 상태 검증
→ 준비된 패턴 실행
```

표시 항목:

- 물리/주문/정신 피해 유형
- 대상 또는 전체 공격 여부
- 예상 피해
- 타격 횟수
- 관통률
- 출혈·독 등의 추가 효과
- 반격·반사 남은 횟수
- 화약 적재량과 다음 포격 횟수
- 등불 충전량과 다음 정신 피해
- 조준 또는 포식 대상
- 포식 저지 요구 피해

도발 등으로 일반 공격 대상이 바뀔 수 있으면 적 턴 직전에 재검증한다. 조준과 포식처럼 대상을 잠근 행동은 재선택하지 않는다.

## 소환, 도주와 골드

### 전투 슬롯

전투의 네 슬롯 제한은 유지한다.

```text
enemySlots: 비활성 슬롯까지 포함해 항상 네 칸 유지
enemyParty: 현재 전투에 존재하는 적
spawnQueue: 소환됐지만 아직 행동할 수 없는 적
```

- 소환 시 첫 빈 슬롯을 사용한다.
- 소환된 적은 화면에는 즉시 등장한다.
- 소환된 적은 다음 적 턴부터 행동한다.
- 소환된 적에게 런타임 `하수인` 표시를 부여한다.
- 소환 최대 수와 전체 적 최대 네 명 제한을 지킨다.

### 도주

- 도주는 사망과 다른 전투 이탈 사유다.
- 도주한 적은 즉시 대상과 적 파티에서 제외된다.
- 도주는 처치 관련 효과를 발동하지 않는다.
- 마지막 적이 도주하면 플레이어 승리다.

### 골드 탈취

- 골드는 현재 시스템이 허용하는 최저치보다 낮아지지 않는다.
- 신용 관련 효과로 최저 골드가 -300이라면 -300 아래로 내려가지 않는다.
- 실제 탈취량만 전투 원장에 기록한다.
- 무장 상인 처치 시 실제 탈취량을 반환하고 추가 골드를 지급한다.
- 무장 상인 도주 시 탈취 골드는 반환하지 않는다.
- 플레이어 패배 시 이미 탈취된 골드는 유지한다.
- 보상은 중복 지급되지 않아야 한다.

처음부터 별도 범용 경제 프레임워크를 만들지 말고 기존 `BattleManager`와 `ResourceManager` 흐름 안에서 최소 상태로 처리한다.

- 패턴: 방어 5 복구 + 도발(3회) + 방어막 12 → 물리 7 + 다른 적 전체 보호(각 1회) → 물리 5×3 + 공격 후 힘 +1(전투 중 영구) + 방패 내리기
- 방패를 내린 순간부터 다음 첫 행동 전까지 방어가 0이다.
- 역할: 도발과 보호로 아군을 지키다가 방패를 내리고 연타하는 보호·교대형
- 세력: 흑철방패 용병단

#### 재의 인도자

- 체력 42 / 정신 60 / 방어 0 / 마저 4
- 패턴: 종말의 종지기 1명 소환, 최대 소환 시 종말의 종지기 전체 힘 +1 → 자신을 제외한 모든 적의 현재 체력 20% 소모 + 실제 소모 체력만큼 의식 축적 → 전체 정신 피해 3 + 의식 수치 3당 정신 피해 +1(최대 +5) + 공격 후 기본 정신 피해 +1, 의식 초기화
- 종말의 종지기는 최대 2명까지 존재한다.
- 체력 소모량과 의식 비례 정신 피해는 소수점 올림한다.
- 기본 정신 피해 증가는 전투 중 누적된다.
- 역할: 순례자를 소환하고 아군 체력을 의식에 사용해 광역 정신 공격을 강화하는 소환·정신공격형
- 세력: 재의 순례자

### 보스 3종

#### 황금낙타 대상주

- 체력 100 / 정신 80 / 방어 5 / 마저 6
- 패턴: 공용 골드 20 탈취 + 방어막 12 → 흑철방패 용병 1명 고용, 최대 고용 시 고용된 용병 전체 체력 10 회복 → 다른 적 전체 방어막 8 + 힘 +1(전투 중 영구) → 단일 주문 10 + 공격 후 증폭 +1(전투 중 영구)
- 흑철 방패병, 계약 결투사, 흑철 쇠뇌수 중 현재 전투에 없는 용병을 무작위로 고용한다.
- 대상주를 포함해 적은 최대 4명이다.
- 처치 시 실제 탈취 골드 반환 + 추가 50골드다.
- 역할: 용병을 지속 고용·강화하면서 자신도 성장하는 소환·지원형
- 세력: 황금낙타

#### 쌍월도 대장

- 체력 105 / 정신 45 / 방어 6 / 마저 2
- 패턴: 방어 6 복구 + 단일 물리 8 + 출혈 1(3턴) → 단일 물리 5×2 → 단일 물리 4×4 + 마지막 타격 적중 시 출혈 2(3턴) → 칼날 갈기(이후 모든 공격 횟수 +1, 출혈 부여 수치 +1) + 방어 0으로 변경
- 공격 횟수 증가는 최대 +3회까지 누적된다.
- 출혈 부여 수치 증가는 전투 중 누적된다.
- 칼날을 간 순간부터 다음 첫 행동 전까지 방어가 0이다.
- 역할: 단타에서 연타로 공격을 확대하고 주기적인 무방비 상태를 거쳐 성장하는 연타·출혈형
- 세력: 붉은 모래단

#### 사막을 삼키는 자

- 체력 140 / 정신 20 / 방어 10 / 마저 0
- 패턴: 단일 물리 10 → 전체 물리 6 → 무작위 대상 1명 포식 예고 + 방어 0으로 변경 → 포식 저지 실패 시 예고 대상에게 물리 15 + 체력 15 회복 + 공격 후 힘 +1(전투 중 영구), 성공 시 행동 실패 → 모래 갑각 재생(방어 10 복구 + 방어막 10) + 이후 포식 저지 필요 피해 +2
- 포식 예고 이후 다음 행동 전까지 사막을 삼키는 자에게 요구량 이상의 피해를 주면 포식을 저지한다.
- 초기 요구 피해는 6, 최대 10이다.
- 실제 체력 피해와 보호막에 실제로 가한 피해를 저지 피해에 포함한다.
- 방어로 감소한 피해는 포함하지 않는다.
- 포식 대상이 실행 전에 사망하면 행동은 실패한다.
- 세 번째 행동부터 다섯 번째 행동 실행 전까지 방어 0을 유지한다.
- 역할: 포식 예고 중 드러나는 약점을 공략하지 못하면 피해·회복·성장으로 이어지는 충전·조건부형
- 세력: 사막 생물군

## 편집기 요구사항

기존 `Window > Battle > 캐릭터 편집기`를 확장한다. 새 창을 중복 생성하지 않는다.

적 편집 화면 구성:

1. 기본 능력치
2. 등급, 세력과 역할
3. 전투 런타임 변수
4. 패턴 타임라인
5. 소환, 도주와 보상
6. 검증 및 피해 미리보기

적에게 사용하지 않는 아군 스킬 필드는 숨긴다. 적의 숨겨진 `baseAttack`과 `spellPower`가 패턴 피해에 중복 적용되지 않도록 편집 흐름을 명확히 한다.

각 패턴 행동은 카드 형태로 표시하고 다음을 지원한다.

- 추가, 삭제, 복제
- 위/아래 순서 변경
- 효과별 대상 설정
- 공격 전/본 행동/타격 후/공격 후 시점 설정
- 기간제/영구/횟수/다음 페이즈 지속 방식
- 선언된 런타임 변수 드롭다운
- 예상 피해와 타격 횟수 표시

행동 종류를 선택하면 필요한 필드만 노출한다. 사용하지 않는 범용 숫자 필드를 늘어놓지 않는다.

필수 편집기 검증:

- 패턴 없음
- 최대 약 5패턴 초과 경고
- 대상 또는 수치 누락
- 상태 지속 방식 누락
- 존재하지 않는 변수 참조
- 공격 후 강화 순서 오류
- 사이클 종료 자동 성장 사용
- 소환 데이터 누락
- 소환 최대 수 초과
- 소환형 인카운터의 빈 슬롯 부족
- 보급 마차꾼 단독 배치
- 플레이어 최저/최고 능력치 기반 대상 지정 경고
- 적 전체 회복이 공격 대상으로 잘못 실행되는 설정

간단한 밸런스 미리보기는 기준 플레이어 체력 30, 정신 30, 방어 3, 마저 3을 대상으로 목표 턴까지 적 패턴을 펼쳐 다음을 표시한다.

- 턴별 체력 피해
- 턴별 정신 피해
- 연타 횟수
- 출혈·독 부여량
- 성장 수치
- 공격하지 않는 준비 턴
- 폭발 공격 턴
- 방어 0과 같은 무방비 구간

전체 자동 전투 AI 시뮬레이터는 만들지 않는다.

## 최소 테스트 목록

- 피해 3, 방어 3은 0이다.
- 피해 3.1, 방어 3은 1이다.
- 물리 3×2, 방어 2는 총 2다.
- 보호막이 모두 흡수하면 실제 체력 피해는 0이다.
- 순수 정신 피해는 방어, 마저와 보호막을 무시한다.
- 체력 피해 0이면 `피해 성공 시 정신 피해`가 발동하지 않는다.
- 실제 체력 피해 비례 정신 피해가 정확하다.
- 힘 +1이 다음 물리 공격의 각 타격에 +1을 준다.
- 공격 후 힘 증가는 현재 공격에 적용되지 않는다.
- 기간제와 영구 상태가 동시에 표시되고 합산된다.
- 보호막은 다음 자기 진영 페이즈에 제거된다.
- 도발, 보호, 반격과 반사가 각 타격마다 차감된다.
- 반격과 반사는 재귀적으로 서로를 다시 발동시키지 않는다.
- 보호막 파괴 초과량은 체력 피해로 전환되지 않는다.
- 출혈 즉시 발동은 남은 턴을 감소시키지 않는다.
- 조준 대상 사망 시 공격이 실패한다.
- 일반 기억 대상 사망 시 새 무작위 대상을 선택한다.
- 소환된 적은 같은 적 턴에 행동하지 않는다.
- 하수인 처치 효과가 기본적으로 발동한다.
- 도주한 적은 처치 효과를 발동하지 않는다.
- 마지막 적 도주 시 승리한다.
- 골드는 허용 최저치 아래로 탈취되지 않는다.
- 골드 반환과 추가 보상이 중복 지급되지 않는다.
- 포식 저지 피해에 실제 체력 피해와 보호막 피해만 포함된다.
- 포식 요구량이 최대 10을 넘지 않는다.
- 적 최대 네 명과 소환 최대 수가 지켜진다.
