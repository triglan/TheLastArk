# Mirage 적 구현 변경 기록

기준: 제공된 약한 적 6종·중간 적 6종·강한 적 5종·엘리트 3종·보스 3종 기획서.

## 적용 내용

- 23종의 실제 CharacterData 에셋과 생성 코드에 기획 수치·패턴을 함께 반영.
- 징수자·호위대장·쌍월도 연타 횟수 복구, 쌍월도 성장은 피해 대신 공격 횟수(+3 상한)에 적용. 마지막 타격 전에 반격으로 중단되면 추가 출혈 미적용.
- 종지기는 단일·전체 정신 공격 모두 성장. 화약 행상인은 기본 1회로 시작해 첫 포격 3회.
- 계약 결투사 2단계, 피칼잡이 3단계, 흑철 기수 4단계, 호위대장 3단계로 수정.
- 관통 50% 실제 적용. 낙마·방패 내리기·연마·포식 예고의 방어 변화는 해당 행동 직후 적용하며 정해진 행동에서 복구.
- 탈피는 최대 2회: 첫 번째 방어 0·힘 +2, 두 번째 힘 +1. 이후 방어막만 획득.
- 가시 반사는 상대 최종 공격력의 50% 기준. 남은 반사 횟수를 가시 모양으로 표시.
- 등불 방출은 충전당 피해 × 충전량의 단일 정신 피해. 의식은 방어막을 우회해 현재 체력 20%를 올림하여 소모하고, 실제 소모한 체력만 축적.
- 대상주가 현재 존재하는 용병을 중복 고용하지 않도록 변경. 전체 적 4명 제한, 본인을 제외한 지원, 증폭 상태효과 적용. 소환된 적은 다음 적 단계부터 행동하며 슬롯 재사용 시 패턴 초기화.
- 포식 저지는 보스 자신의 체력·방어막 피해 합계로 판정.
- 공격·출혈·독·방어막 파괴의 지정 대상 유지. 보급 마차꾼은 다른 적 1명과 편성.
- 조준·돌진·포격·등불·포식의 준비 시 공격 수치 예고 추가. 목격자의 눈 감음 상태 및 선택 그림 전환 지원.

## 그림 자동 연결

`Assets/Sprites/Monster/1. mirage`에 `몬스터 이름.png` 저장 시 Sprite 가져오기 설정과 적 데이터 연결을 자동 수행. 공백·밑줄·하이픈 및 한글 Unicode 정규화 차이 허용.

- 선택 초상화: `몬스터 이름_portrait.png`
- 목격자 눈 감은 그림: `마지막 목격자_closed.png`
- 중복 이름은 경고 후 연결을 건너뜀. 수동 재연결은 `Tools > Battle > Bind Mirage Monster Illustrations`.
- 새 몬스터 오브젝트를 임의로 생성하지 않으며 기존 전투 슬롯이 연결된 그림을 표시.
- 그림 폴더는 작업 시점에 비어 있었으므로 실제 일러스트의 구도·여백·전투 화면 크기는 그림 추가 후 확인 필요. 눈 감은 그림이 없으면 기본 그림과 상태 표시 사용.

전투 정의를 다시 적용하려면 `Tools > Battle > Apply Mirage Enemy Specification`. 이 메뉴는 기획서 수치로 전투 데이터를 덮어쓰므로 이후 수동 밸런스 조정을 보존하려면 실행하지 않을 것. 그림 및 일치하는 행동의 아이콘·VFX 참조는 보존.

## 검증

- 기존 전투 테스트 23개, 적 기획 회귀 테스트 17개, PNG 자동 연결 통합 테스트 1개, Play Mode 핵심 전투 테스트 1개: 총 42개 통과.
- Play Mode: 기수 돌진과 재기승, 포식 저지, 반격에 의한 연타 중단 확인.
- 자동 연결: 실제 임시 PNG 가져오기, 별도 초상화 우선 적용, 중복 파일 보존 확인. 임시 에셋 정리 완료.
- 별도 Preview Scene에서 예고 UI·가시 개수 렌더 확인. 기존 MapScene 복원, 컴파일 오류 없음.
- 전체 23종을 실제 맵에서 각각 조우하는 장시간 밸런스 플레이는 별도 진행 대상.
