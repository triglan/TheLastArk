# Mirage 지역과 몬스터 배치

## 일러스트 조절

`Shift + E → 적 → 몬스터 선택 → 일러스트 크기 / 배치`에서 조절한다.

- **키 (cm)**: 170, 180, 200처럼 입력한다. 기본 180cm는 전투 UI 높이 525단위로 표시되며, 170cm는 그보다 약 6% 작다. 원본 이미지 비율을 유지하고 해상도와 관계없이 입력한 키에 맞춘다. 실제 화면 픽셀 수는 Canvas 배율에 따라 달라진다.
- 이전 배율 값은 더 이상 렌더링에 사용하지 않는다. 새 키 설정의 기본값은 180cm이며 기존 X/Y 위치와 발밑 고정은 유지된다. 이미지의 투명 여백도 높이에 포함되므로 비슷하게 잘라낸 이미지를 사용하는 것이 좋다.
- **위치 X / Y**: 전투 UI 좌표 기준. X 양수는 오른쪽, Y 양수는 위쪽이다.
- **발밑 기준 유지**: 크기와 이미지 비율이 달라도 이미지 하단을 기존 슬롯 하단에 맞춘다. 이미지 내부의 투명 여백은 Y 위치로 보정한다.
- **크기 / 위치 초기화**: 키 180cm, X/Y 0, 발밑 기준 유지 켜기로 복구한다.
- 변경값은 캐릭터 데이터에 자동 저장된다. 전투 중 체력바와 상태 표시는 일러스트 머리 위에, 이름은 발밑에 맞춰 따라간다.
- 플레이 중 편집했다면 **현재 전투에 배치 반영** 버튼으로 적용한다. 다음 전투에서는 자동 적용된다.

포메이션 탭에도 4개 슬롯 미리보기와 연결된 지역·풀·층 범위가 표시된다. 미리보기는 Enemy Character 프리팹 기준이며, 선은 발밑 기준이고 테두리는 기준 키 180cm이다.

## 전투 화면 배치

- 적 1~4명을 전투 영역에 균등 배치하며, 쓰러진 적을 제외하고 다시 가운데 정렬한다. 일러스트 하단은 하단 스킬 영역 위에 맞춘다.
- 180cm 기준 크기를 이전보다 25% 키웠다. 화면 높이와 적 수에 따른 가로 공간이 부족하면 전체 적을 같은 비율로 줄여 키 차이를 유지한다.
- 다음 행동은 머리 위에 아이콘·수치로 표시하며, 마우스를 올리면 대상과 상세 효과를 보여준다.
- 체력·정신력 아래에 방어와 상태 아이콘을 표시한다. 상태의 남은 턴/횟수는 숫자로 표시하고 설명은 툴팁으로 제공한다. 고유 강화 변수도 별도 작은 표시와 툴팁을 사용한다.
- 주사위는 하단 스킬 패널의 위쪽 행에 배치한다. 주사위 모드에서는 카드 간격을 조정해 같은 패널 안에 수용하며, 기존 드래그 입력을 유지한다.

## 지역 → 풀 → 포메이션 → 적

`Shift + E → 풀 → 새 런 시작 지역`은 새 런의 시작 지역을 정한다. 현재 시작 지역은 `mirage`이다. 진행 중인 런은 `RunState.currentRegionId`를 유지하며, 새 런 초기화 시 다시 시작 지역을 읽는다. 다른 지역 진행을 추가할 때 해당 지역의 풀을 등록하고 런의 `currentRegionId`를 변경하면 된다. 이번 작업에는 다음 지역으로 넘어가는 맵/보스 클리어 연출은 포함되지 않는다.

| 노드 | 맵 층 | 포메이션 수 |
|---|---:|---:|
| 일반 | 1~3 | 5 |
| 일반 | 4~5 | 6 |
| 일반 | 6~10 | 6 |
| 일반 | 11~15 | 7 |
| 엘리트 | 1~15 | 6 |
| 보스 | 1~15 | 3 |

23개 몬스터, 33개 포메이션, 6개 풀을 연결했다. 기존 슬롯 조합과 보상 단계는 유지한다. 층은 맵의 `node.floor`이며 전투 횟수와 다르다.

지역·노드 종류·층·전투 횟수가 일치하는 유효한 풀 중 우선순위가 가장 높은 풀을 선택한다. 해당 풀에서 아직 만나지 않은 포메이션을 우선 선택하고, 모두 만났다면 같은 풀 안에서 재등장을 허용한다. 빈 풀은 제외한다. 조건에 맞는 풀이 없을 때 다른 지역/층의 적으로 대체하지 않고 전투 진입을 중단하며 오류를 기록한다.

`Tools → Battle → Connect Mirage Region`은 기존 Mirage 에셋의 지역 연결을 다시 적용하는 수동 복구 메뉴이다. 시작 지역도 `mirage`로 설정하므로 다른 지역으로 변경한 뒤에는 필요할 때만 실행한다. 일반 편집 때 이 메뉴를 실행할 필요는 없다.

일러스트는 계속 `Assets/Sprites/Monster/1. mirage/몬스터 이름.png`로 자동 연결된다. 이미지 교체 및 전투 수치 갱신 시 크기/위치 설정은 유지된다.
